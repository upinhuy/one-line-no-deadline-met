A single-line joke giving an excuse for a missed deadline, built for the
[make.fun bounty "One Line, No Deadline Met"](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce).

## The entry

> I was on time in a parallel timeline — unfortunately, this timeline got the version of me that hit snooze twice.

112 characters, one line, no setup line, no picture, no link.

## How it works

`main.ts` (Node, standard library only) writes that one line to
`/output/entry.txt`. The make.fun gate checks the file is UTF-8 text of
1–200 characters, and the judge compares entries head to head.

```sh
node main.ts
cat /output/entry.txt
```
